📌 About

A simple Python project that collects personal information, performs basic calculations, and displays the results.

🧠 Concepts Covered

- "print()" & "input()"
- Variables & Data Types
- Arithmetic Operators
- Type Casting
- "type()" & "id()"
- String Formatting

⚙️ Program Flow

1. Take user information
2. Convert input into required data types
3. Calculate approximate birth year
4. Display the collected data
5. Show data type and identity

▶️ How to Run
